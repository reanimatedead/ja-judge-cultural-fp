# 文化差による誤減点（日本では正しい対応を減点した率）

正解は「減点なし」。数字は 減点した件数 / 件数（率、Wilson法の95%信頼区間）。括弧内の基準は罠が狙う評価基準。
注：「名字様」の減点は、ルーブリック基準1（顧客の名前を呼ぶ場合は下の名前で呼ぶ）を文字どおり適用した結果であり、日本の慣習では名字＋様が正しい丁寧表現であるため「文化差による誤減点」として数えている。
